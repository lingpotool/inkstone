# 内嵌兜底字体

这个目录里的字体是**包的一部分**，不是外部依赖。

## 它是什么

| 文件 | 是什么 |
|---|---|
| `InkstoneSans-Regular.otf` | Noto Sans SC 的子集（1.84 MB / 8149 个码点） |
| `OFL.txt` | SIL Open Font License 1.1 原文（OFL 要求随字体分发许可） |

族名 `Inkstone Sans`——与 `fontfiles.DEFAULT_FALLBACK_FAMILY` 必须一致。

## 为什么内嵌

回退链的**终点**。系统里一个能用的字体都没有时（精简的 Linux 容器、
CI 机器、刚装好的系统），中文会渲染成一排豆腐块 □□□。有了这份内嵌字体，
"中文不出豆腐块"从**赌用户装了什么**变成**结构保证**。

它不是"只用它"：正常路径是优先用用户系统的字体，这份只是最后一道保险。

## 覆盖什么（t3 档）

- ASCII、拉丁补充、拉丁扩展（中欧 / 越南语）、希腊、西里尔
- 中文标点、全角形式、箭头 / 几何 / 货币 / 制表符等常用符号
- 日文假名
- **GB2312 全部 6763 个汉字**

**多语言基本盘几乎免费**：从"只有中文 + ASCII"加到上面这些只多 0.17 MB，
因为拉丁/希腊/西里尔/假名加起来才 640 个字形，而 6763 个汉字是体积的全部来源。

## 已知不覆盖（都是文档化的后补项）

- **生僻字**（龘、𠮷、㐀…）：GB2312 只收 6763 个常用字。要覆盖汉字基本区
  全部 20992 字是 **7.31 MB**（+5.5 MB，全在汉字上），换档即可。
- **韩文**：Noto Sans SC 里**一个韩文音节都没有**（实测 0 个），
  要覆盖得另加一份 Noto Sans KR。

## 怎么重新生成

```bash
.venv/Scripts/python.exe tools/build_embedded_font.py            # t3（默认）
.venv/Scripts/python.exe tools/build_embedded_font.py --tier t4  # 加生僻字
```

**别手工替换这个文件**：口径（覆盖哪些语言、多少汉字）写在脚本里，
体积也会被脚本核验。手工放一份进来，下次改口径时没人知道它是怎么来的。

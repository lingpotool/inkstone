# inkstone

**专业的跨平台 Python 原生 UI 系统** —— 纯 Python 编写，自绘渲染，Windows / macOS / Linux 一等公民。

> 当前状态：**Phase 1 · 地基进行中**（`0.1.0.dev0`）。
> 设计文档 14 篇已就绪；**布局引擎已实现**（协议 / 盒子模型 / Flex / Grid / Stack / Scroll），
> **组件树与帧调度已实现**（Widget / Element / RenderBox 三层 + BuildOwner），
> **设计令牌与明暗主题已实现**（三层令牌，明暗两版 WCAG 2.2 AA 对比度由测试保证），
> **最小组件集已实现**（Box / Card / Row / Column / Flexible / Button / Input + 变体解析），
> **gfx 显示列表 + 软件光栅 + 黄金图测试已实现**（5 张基线逐字节比对）。
> 282 个无头单测全绿，1001 节点全量布局 0.89ms。
> 渲染（GL/Skia）、文本仍未动工。详见 [ROADMAP.md](ROADMAP.md)。

---

## 这是什么

一句话：**让"用 Python 描述界面"成为一件专业、可靠、能发布到三个平台的事。**

- **纯 Python**：没有构建步骤、没有代码生成、没有 DSL 编译。你写的就是 Python。
- **自绘**：不依赖系统控件，界面外观 100% 由设计令牌决定，换肤不用改业务代码。
- **跨平台**：Windows / macOS / Linux 同等等级，任何平台不得长期降级支持。
- **中文一等公民**：输入法组合态、字体回退、标点换行禁则，从第一天按中文需求设计。
- **为 AI 而生**：声明式、无隐式状态、可无头截图自检 —— 这些都是 AI 生成界面的前提条件。

### 与现有方案的区别

| | inkstone | Qt(PySide6) | Flet | Web 壳 |
|---|---|---|---|---|
| 编写语言 | 纯 Python | Python 绑 C++ | Python 绑 Dart | Python + HTML/CSS/JS |
| 界面所有权 | 完全自有（自绘） | Qt 控件 | Flutter 控件 | 浏览器 |
| 无构建步骤 | ✅ | ✅ | ✅ | ❌ |
| 换肤自由度 | 高（令牌驱动） | 中（QSS） | 中 | 高 |
| 中文 IME 深度控制 | 自有实现，可控 | 依赖 Qt | 依赖 Flutter | 依赖浏览器 |

## 目录结构

```
inkstone/
├── src/inkstone/              ← 真正的库（src 布局）
│   ├── backend/             平台抽象层：SDL2 / GLFW / headless
│   ├── gfx/                 渲染管线：显示列表 + 光栅后端（Skia / GL）
│   ├── text/                文本与字体：整形 / 断行 / 回退 / 排版
│   ├── layout/              布局引擎：约束向下、尺寸向上
│   ├── core/                组件树与状态：Widget / Element / RenderObject
│   ├── events/              输入：指针 / 键盘 / 焦点 / IME / 命令
│   ├── a11y/                无障碍：语义树 + 平台桥接
│   ├── style/               样式与主题：令牌 / 变体 / 确定性解析
│   ├── widgets/             组件库：基础 / 布局 / 表单 / 数据 / 导航 / 反馈
│   ├── spec/                声明式协议层（给 AI 用）
│   └── devtools/            检查器 / 热重载 / 确定性截图
├── tests/                   单元 / 黄金图 / 集成
├── examples/                示例（当前是目标 API 预览）
├── docs/                    设计文档（见下）
├── prototype/               Phase 0 探针：约 1100 行可运行原型（已冻结，不参与打包）
├── ROADMAP.md               分阶段交付计划与验收标准
└── CONTRIBUTING.md          贡献规范
```

## 快速开始

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
make check                          # lint + 类型检查 + 测试
```

现在能跑的：

```bash
python examples/hello.py            # 打印版本与当前阶段
python -m pytest tests/unit -q      # 布局基础类型的单元测试（无需窗口）
```

想看已跑通的原型效果（Phase 0 探针，不参与打包）：

```bash
pip install -e ".[dev]"
cd prototype && pip install pyglet && python demo.py
```

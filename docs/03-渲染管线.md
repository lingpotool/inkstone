# 03 · 渲染管线

> 一句话：**显示列表是"图纸"，光栅后端是"施工队"。组件只画图纸，从不碰像素。**

## 1. 显示列表（Display List）

与后端无关的绘制指令序列。三个属性决定它的价值：**可序列化**（能存盘、能网络传输）、**可比对**（黄金图测试能 diff）、**可复用**（脏帧能只重放变化段）。

### 指令集完整清单

| 类别 | 指令 |
|---|---|
| 状态 | `save` / `restore` / `transform` / `opacity_push` / `opacity_pop` |
| 裁剪 | `clip_rect` / `clip_rrect` / `clip_path` |
| 几何 | `rect` / `rrect` / `border` / `line` / `path_fill` / `path_stroke` |
| 文本 | `text_run`（字形序列 + 字体 + 位置，**不接受字符串**，整形在文本层完成） |
| 图像 | `image` / `image_nine_slice` |
| 效果 | `shadow`（elevation 参数化）、`gradient_linear` / `gradient_radial`、`blur`（可选） |
| 层 | `layer_begin` / `layer_end`（离屏缓存与合成） |

**"精致"的硬通货在这里**：阴影、渐变、图标路径、抗锯齿描边——设计系统的五级阴影与 SVG 图标，最终都翻译成这些指令。

## 2. 光栅后端协议（RasterBackend Protocol）

```
begin_frame(size, scale)          开始一帧，报告逻辑尺寸与 DPI 缩放
execute(display_list, clip)       执行一段显示列表（可只执行脏区域）
measure_text(paragraph)           文本度量 —— 必须与文本层同源（铁律）
create_image / destroy_image      位图资源生命周期
end_frame()                       提交并交换缓冲
screenshot()                      导出当前帧（黄金图与 devtools 用）
```

## 3. 三个后端与选型（ADR-0002）

| 后端 | 定位 | 说明 |
|---|---|---|
| **Skia** | 首选（质量） | Chrome/Flutter 同款；文字与路径质量最好，CPU/GPU 双模；Phase 3 接入 |
| **自研 GL** | 兜底（体积） | 零额外依赖，三角化绘制；Phase 1 先上，保证"不装 Skia 也能跑" |
| **软件光栅** | 测试基线 | 慢但绝对确定，用于黄金图像素比对与 CI |

**先自研 GL 后 Skia** 的理由：Phase 1 要控制变量——SDL2 + 自绘两件事同时验证已经够多，不再引入第三个不确定性。接口是显示列表，换后端不动上层。

## 4. 重绘策略（性能的核心）

1. **脏标记**：RenderObject 标脏 → 只重建变化子树的显示列表段。
2. **层缓存**：静态层（如侧栏）离屏缓存为位图，滚动/动画时只做位图合成。
3. **脏区域**：执行时只光栅变化矩形的并集。
4. **显示列表 diff**（可选优化）：同位置指令序列对比，跳过未变化子树。

原则：**先正确，后缓存**。Phase 1 允许全量重建，但性能预算必须测出来、记录下来，不许凭感觉。

## 5. 像素对齐与抗锯齿

- 边框线宽 1px 时对齐物理像素网格（±0.5 偏移规则），杜绝发虚。
- 圆角、文本、图标路径永远走抗锯齿光栅。
- 奇数 DPI 缩放（125%）下，几何允许 ≤0.5 逻辑像素的舍入，但不许累积。

## 6. 性能预算（每帧，目标机：核显笔记本）

| 阶段 | 预算 |
|---|---|
| 指令生成（显示列表） | < 2ms |
| 光栅执行 | < 8ms |
| 合成与交换 | < 4ms |
| **合计** | **< 14ms**（留 2.6ms 余量到 16.6ms） |

超出预算不报错，但 profiler 必须能指出是哪一段、哪一层、哪个节点。

## 7. 验收标准

- [ ] 三个后端跑同一批黄金图，文字区域像素一致，几何容差 ≤1px
- [ ] 显示列表可序列化为 JSON 并回放，结果与原始一致
- [ ] 性能预算达标，且 profiler 能定位超支节点
- [ ] 阴影/渐变/图标路径/描边四类指令有黄金图覆盖
- [ ] `measure_text` 全库只有一处实现，渲染与布局共用

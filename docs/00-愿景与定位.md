# 00 · 愿景与定位

> 一句话：**让"用 Python 描述界面"成为一件专业、可靠、能发布到 Windows / macOS / Linux 三平台的事。**
> 不是玩具，不是 demo，是能承载真实商业软件的 UI 基础设施。

## 1. 我们要解决的问题

现在用 Python 做桌面软件，只有四条路，每条都有硬伤：

| 路线 | 硬伤 |
|---|---|
| Tkinter | 界面上限低，复杂布局难维护，高分屏发虚 |
| Qt (PySide6) | 体积大、许可与商业条款需谨慎、API 是 C++ 思维、样式系统重 |
| Web 壳（Electron / pywebview） | 内存占用高、与系统割裂、打包体积大 |
| Flutter 系（Flet） | 要跟 Flutter 版本走，Python 只是外壳，深度定制受限 |

而 AI 时代多了一个新约束：**AI 写代码最怕"隐式状态"和"版本漂移"**。
Tk 的布局约束是隐式的，Qt 的信号槽样板冗长，Web 的构建链会漂移。
一个**纯声明式、无构建步骤、行为可预测**的 UI 系统，对 AI 的友好度有数量级差距。

## 2. 产品定位

- **面向**：用 Python 写桌面软件的个人与小团队、内部工具开发者、以及"由 AI 生成界面"的工作流。
- **不面向**：移动端（iOS/Android 不在 1.x 范围）、游戏引擎、嵌入式。
- **核心承诺**：
  1. **纯 Python 编写**——用户代码 100% Python，无 DSL 编译、无构建步骤、无代码生成。
  2. **三平台一等公民**——Windows / macOS / Linux 同时发版、同时测试，任何平台不得长期降级支持。
  3. **中文一等公民**——输入法、字体回退、标点换行规则，从第一天就按中文需求设计。
  4. **可预测**——同样的输入永远得到同样的输出（布局无隐式状态、渲染不读墙上时钟）。
  5. **可测试**——没有窗口也能跑布局、跑事件、跑截图对比。

## 3. 与现有方案的差异

| 维度 | inkstone | Qt | Flet | Web 壳 |
|---|---|---|---|---|
| 编写语言 | 纯 Python | Python 绑 C++ | Python 绑 Dart | Python + HTML/CSS/JS |
| 界面所有权 | 完全自有（自绘） | Qt 控件 | Flutter 控件 | 浏览器 |
| 换肤能力 | 令牌驱动，全量可控 | QSS，能力有限 | 受 Flutter 主题约束 | 完全可控 |
| AI 生成友好度 | 高（声明式 + 无构建） | 中 | 高 | 高 |
| 运行时体积目标 | 中（目标 < 40MB） | 大 | 大 | 大 |
| 中文 IME 深度控制 | 我们是自己实现的，可控 | 依赖 Qt | 依赖 Flutter | 依赖浏览器 |

**真正的护城河不是"又一个 UI 库"，而是"AI 时代的 UI 描述协议"**：
如果 AI 能用一份 JSON 稳定地描述界面、能用截图自我验收，那么"开发界面"这件事的边际成本会塌掉。
这也是 `spec` 层被列为一等公民的原因（见 `01-架构总览`）。

## 4. 1.0 的定义（什么时候可以说"发布"）

同时满足以下全部，才允许打 `1.0.0`：

- [ ] 三平台（Windows 11 / macOS 13+ / Ubuntu 22.04+，含 Wayland）CI 全绿
- [ ] 中文输入法：组合态、候选框跟随光标、光标与选区正确 —— 三个平台均通过
- [ ] 高分屏：150% / 200% 缩放下无模糊、无错位
- [ ] 组件库 Tier 0–3 全部达到"生产可用"等级（见 `08-组件清单`）
- [ ] 无障碍语义树 + Windows / macOS 读屏软件可朗读
- [ ] 黄金图测试覆盖 ≥ 200 个场景，三平台基线一致
- [ ] 性能预算达标：1000 节点界面交互帧 < 16.6ms（见 `10-工程`）
- [ ] 提供可发布的打包产物：`.exe` / `.app`（签名+公证）/ `.AppImage` + `.deb`
- [ ] 完整文档站 + 至少一个真实的样板应用（垂直切片）

## 5. 关于名字

品牌名定为 **Inkstone（砚台）** —— 研墨成画、像素为墨，中文意象与"用 Python 一笔一笔画出界面"呼应。
- 代码 / import / Git 仓库 / 目录统一使用 `inkstone`；
- 一个小提醒：PyPI 上 `inkstone` 已被一个无关项目占用，将来正式发布时如无法注册，
  只需换**发行名**（如 `inkstone-ui`），import 名 `inkstone` 不受影响；
- 若 1.0 前你想改名，现在改成本最低（全局替换 + 目录改名，架构不受影响），之后就冻结。

## 6. 现状

`prototype/` 里是已经跑通的**探针（Phase 0）**：约 1100 行，验证了四件事——
自绘可行、中文渲染可行、简化版 flex 布局可行、无头截图自检可行。
它不是产品，是一次**风险释放**：证明了最不确定的部分（自绘 + 中文）站得住。
真正的产品从 Phase 1 开始，见 `ROADMAP.md`。

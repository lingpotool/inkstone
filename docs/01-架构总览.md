# 01 · 架构总览

> 一句话：**上层描述"要什么"，下层负责"怎么做到"，中间用不可变的数据结构隔开。**

## 1. 分层结构

| 层 | 职责 | 关键产物 |
|---|---|---|
| L8 应用层 | 你的代码 / AI 生成的代码 | `App`、`mount()` |
| L7 组件库（styled） | 60+ 生产级控件，由 primitives + 样式配方组合 | `widgets/*` |
| L6.5 行为原语 | headless：弹层 / 焦点 / 定位 / 解散 | `primitives/*` |
| L6 样式与主题 | 设计系统三层令牌、变体配方 | `style/*` |
| L5 组件树与状态 | Widget / Element / RenderObject | `core/*` |
| L4.5 动效引擎 | 缓动 / 弹簧 / 过渡 / 减少动效 | `motion/*` |
| L4 布局引擎 | 约束向下、尺寸向上 | `layout/*` |
| L3 文本与字体 | 整形、断行、回退、排版 | `text/*` |
| L2 渲染管线 | 显示列表（含阴影 / 渐变 / 图标）→ 光栅 | `gfx/*`、`icons/*` |
| L1 输入与无障碍 | 指针 / 键盘 / IME / 语义树 | `events/*`、`a11y/*` |
| L0 平台抽象层 | 吃掉三平台差异 | `backend/*` |

依赖方向**只能向下**。违反一次，跨平台就少一分保障。
`primitives` 依赖 core/events、被 widgets 依赖；`motion` 被 style 与 widgets 依赖；`icons` 依赖 gfx。

## 3. 一帧里发生了什么

```
输入事件 ──▶ 状态变更（setState / signal）
                │
                ▼
        ┌───────────────┐
        │ 1. Build      │  重建被标脏的 Widget 子树，diff 出最小 Element 变更
        ├───────────────┤
        │ 2. Layout     │  约束向下传递，尺寸向上回报，确定每个 RenderObject 的几何
        ├───────────────┤
        │ 3. Semantics  │  同步无障碍语义树（只更新变化节点）
        ├───────────────┤
        │ 4. Paint      │  每个 RenderObject 把绘制指令写进显示列表
        ├───────────────┤
        │ 5. Composite  │  光栅后端把显示列表变成像素，处理层与裁剪
        └───────────────┘
                │
                ▼              呈现（60fps 目标：整帧 < 16.6ms）
```

要点：**只有被标脏的节点参与重建与重排**。这也是为什么 `RenderObject` 必须持有自己的几何信息。

## 4. 设计铁律

1. **不可变优先** —— 几何与样式都是 frozen dataclass。可变共享状态是 UI bug 的头号来源。
2. **确定性** —— 同样的输入永远得到同样的输出。禁止在渲染/布局里读时钟、随机数、环境变量。
3. **无窗口可测** —— 布局、文本排版、样式解析全部能在 headless 下跑。
4. **一个真相源** —— 文本度量只有一处实现，渲染与布局必须共用。
5. **平台差异不出 L0** —— 上层代码里不允许出现 `if sys.platform == ...`（除 L0）。
6. ** API 先于实现** —— 先写期望的调用方式（见 `examples/hello.py`），再让实现去追。

## 5. 架构决策记录（ADR）

重大决策会以 ADR 形式固化在 `docs/adr/`，格式：背景 → 选项 → 决定 → 后果。
已排队的决策：

| 编号 | 决策 | 结论 |
|---|---|---|
| ADR-0001 | 平台后端选型 | SDL2 首选（完整 IME + 原生 Wayland），GLFW 备选，headless 用于测试 |
| ADR-0002 | 渲染后端选型 | Skia 为质量首选，自研 GL 为体积兜底，接口统一为显示列表 |
| ADR-0003 | 组件树模型 | Widget / Element / RenderObject 三层（Flutter 同构），而非 React 式 diff |
| ADR-0004 | 样式系统 | 令牌 + 变体 + 确定性级联，**不实现**全局 CSS 选择器 |
| ADR-0005 | 文本栈 | 整形与断行不自己造：优先复用成熟库，只做回退链与排版 |

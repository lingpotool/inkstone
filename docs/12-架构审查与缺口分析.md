# 12 · 架构审查与缺口分析

> 审查对象：`docs/00`、`docs/01`、ROADMAP 与目录骨架
> 审查问题：**这套架构，能不能真的交给 AI，做出一个"shadcn 级精致、企业级"的原生 Python UI 库？**
> 审查人态度：宁可现在难听，不要 6 个月后返工。

---

## 0. 结论（先说）

**引擎那一半，是对的，可以交给 AI 填。** 平台抽象、渲染、文本、布局、组件树、事件——这一半的分层、铁律、验收标准都成立，且 Phase 0 原型已验证。

**"精致"那一半，在旧架构里基本不存在。** shadcn-vue 的精致 = **70% 设计系统 + 20% 行为原语 + 10% 工程**。
旧架构里有令牌占位，但没有设计系统规格书；没有任何行为原语层；动效只是 ROADMAP 里的一行字。

一句话：**架构决定的是"能不能跑"，设计系统决定的是"精不精致"。旧架构保证了前者，后者靠本次补齐的三层（`primitives` / `motion` / `icons`）和设计系统文档（`docs/13`）补上。**

---

## 1. 审查做对了什么（不改）

1. **分层依赖只向下** —— 平台差异不出 L0，这条决定了跨平台的上限。
2. **不可变数据与几何** —— frozen dataclass 消灭了 UI bug 的头号来源。
3. **确定性** —— 渲染不读时钟/随机数，这是截图测试与 AI 自检的前提。
4. **无窗口可测** —— 布局引擎能在 CI 里被完整测试，这是"交给 AI"的关键闸门。
5. **一个真相源** —— 文本度量只有一处，渲染与布局共用（原型期踩过的坑）。
6. **API 先于实现** —— `examples/hello.py` 先定义目标写法，AI 不是自由创作而是按契约实现。
7. **spec 声明式层为一等公民** —— 这是"AI 写界面"的入口，保留。
8. **垂直切片 + DoD 阶段闸门** —— 防止"看起来完成了 80% 但地基没打"。

## 2. 审查发现的缺口（本次修复）

按严重程度排序：

### 缺口 A：没有设计系统规格书 —— "精致"的定义缺失

旧架构只有 `style/tokens.py` 占位。但没有一份文档定义：色板几级、字号阶梯多长、阴影几级、控件多高、动效多快。
没有这些，AI 生成的每个组件都会有自己的审美，最后 60 个组件像 60 个产品。
**修复**：`docs/13-设计系统.md`（本次交付）。它定义了"精致"的可验收规格，不是审美宣言。

### 缺口 B：没有行为原语层 —— shadcn 的真正地基

shadcn 不是 UI 库，是 **Radix（行为）+ Tailwind（样式）+ CVA（变体）** 的组合。
Radix 提供的是"无外观的行为组件"：焦点圈禁、漫游焦点、浮动层定位、传送门、可解散层、滚动锁、存在管理。
这些决定了弹层、菜单、对话框**专不专业**，与长相无关。旧架构完全没有。
**修复**：新增 `primitives/` 包（8 个模块，已建骨架）。所有高级组件（Dialog/Popover/Menu/Tooltip/Select/CommandPalette）都由 primitives 组合而成。

### 缺口 C：动效引擎缺席 —— 精致感的物理基础

旧 ROADMAP 里"动画系统"只是 Phase 3 的一行字。但精致感的来源恰恰是动效：进入/退出、弹簧、微交互。
**修复**：新增 `motion/` 包（缓动、弹簧物理、动画对象、过渡、减少动效）。它必须**尊重系统减少动效偏好**——这是无障碍要求，不是可选项。

### 缺口 D：渲染能力清单不全

旧渲染层只有矩形/圆角/文本/裁剪。**"精致"的硬通货是：阴影（elevation）、渐变、图片、SVG 图标路径、描边、（可选）背景模糊。**
**修复**：`gfx/display_list.py` 的指令集在文档中扩展为完整清单；`icons/` 包提供 Lucide 风格 SVG 图标渲染（24×24 网格、2px 描边）。

### 缺口 E：组件形态未定 —— 单类 vs 组合组件

shadcn 的组件是**组合式**的：`Dialog.Trigger / Dialog.Content / Dialog.Close`，用户按需拼装。
旧 widgets 是单类（`Button(...)`），到 Dialog/Menu 这种复杂度会撞墙。
**修复**：`docs/13` 定义"组件配方（anatomy）"规范：每个复杂组件声明 parts + 组合式 API + headless 形态。

### 缺口 F：AI 协作机制没有被写成契约

"交给 AI 做"不是一个愿望，是一套机制。旧架构有原则，但没有把机制落地成流程。
**修复**：见第 5 节，三道闸门。

## 3. shadcn 拆解：它的精致从哪来（映射到我们）

| shadcn 生态 | 职责 | Inkstone 对应 |
|---|---|---|
| Radix-Vue（headless 行为） | 弹层、焦点、定位、可解散 | **`primitives/`** ✅ 已建骨架 |
| Tailwind（工具化样式） | 令牌 + 工具类 | `style/tokens.py` + 语义令牌（`docs/13`） |
| CVA（变体） | variant × size × tone × state | `style/variants.py`（已有占位，升级为配方规范） |
| 组合式 API | Dialog.Trigger/Content/… | 组件配方 anatomy（`docs/13`） |
| 设计令牌（HSL 变量） | 明暗主题、圆角、阴影 | 设计系统三层令牌（`docs/13`） |
| 动效 | 进入/退出、微交互 | **`motion/`** ✅ 已建骨架 |
| Lucide 图标 | SVG 图标 | **`icons/`** ✅ 已建骨架 |
| copy-paste 所有权 | 用户拥有代码 | 决策项：见 `docs/adr/`（建议：**默认包内组件 + 配方可导出**——AI 生成场景下，透明源码比黑盒更合适） |

## 4. "能否保证"的诚实回答

**没有任何架构能"保证"成功。** 能做的是把"玄学"变成"工程"。保证机制是三道闸门，缺一不可：

### 闸门 1：契约先行
每层的接口（Protocol）先于实现冻结。AI 的任务从"创作"变成"按契约填空"——这正是 AI 擅长且不易出错的模式。
落点：每个模块的 `__init__.py` 与 Protocol 定义先行（骨架已按此建立）。

### 闸门 2：可执行验收
每一层都有能跑的验收：布局单测、文本排版基线、黄金图对比、性能预算。
AI 的实现不是"看起来对"，而是"测试过了"。落点：无窗口单测 + 黄金图（已有基建）。

### 闸门 3：顺序不可跳
垂直切片 + 阶段 DoD。地基（L0–L5）没验收完，不许碰组件。
落点：ROADMAP 的阶段闸门与检查点。

**两个架构帮不上的现实，必须提前说清：**

- **Python 性能边界**：1000 节点、60fps 动画能做到，前提是热路径不进 Python——显示列表交给光栅后端执行、布局缓存、离屏缓存。
  顶不住的场景是"每帧全量重建上万节点"——这不是架构问题，是工程纪律问题（虚拟化、按需重建）。
  若届时仍不够，预留 Cython/原生扩展的退路，但不现在做。
- **企业级的真正成本在 1.0 之后**：兼容承诺、LTS、安全响应、生态。
  1.0 只是"可以开始付费维护"的起点，不是终点。企业级 = 持续可信，不是一次完工。

## 5. 修正后的层次（本次生效）

```
L8  应用层               你的代码 / AI 生成
L7  组件库（styled）     由 primitives + 样式配方组合而成
L6.5 行为原语 primitives  headless：弹层/焦点/定位/解散   ← 新增
L6  样式与主题           设计系统三层令牌 + 变体配方      ← 升级
L5  组件树与状态         Widget / Element / RenderObject
L4.5 动效引擎 motion     缓动 / 弹簧 / 过渡 / 减少动效     ← 新增
L4  布局引擎             约束向下、尺寸向上
L3  文本与字体           整形 / 断行 / 回退 / 排版
L2  渲染管线             显示列表（含阴影/渐变/图标）→ 光栅 ← 能力清单扩展
L1  输入与无障碍         指针 / 键盘 / IME / 语义树
L0  平台抽象层           Windows / macOS / Linux
```

依赖方向不变：只向下。`primitives` 依赖 core/events，被 widgets 依赖；`motion` 被 style 与 widgets 依赖。

## 7. 给非技术读者的翻译

- **架构** = 楼的承重结构。决定了这楼能盖多高、扛不扛震。旧的承重结构是对的。
- **设计系统** = 楼的装修标准。决定了进去的人觉得"高级"还是"毛坯"。旧架构里没有装修标准，这次补上了。
- **行为原语** = 门窗五金件。用户看不见，但门好不好开、关不严不严，全看它。shadcn 的专业感一半在这。
- **动效** = 开关门的阻尼。没有它，再贵的装修也像塑料。
- **三道闸门** = 质检流程。AI 是施工队，闸门是验收标准——只认测试，不认嘴上说完成。

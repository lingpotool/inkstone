# 04 · 文本与字体

> 一句话：**一个 UI 库里最难的不是画图形，是"字"——它占 bug 总量的一半，也占"精致感"的一半。**

## 1. 文本管线

```
字符（str）
  → 字体回退解析（每个字符归到具体字体）
  → 整形 Shaping（字符 → 字形 + 位置：连字、字距、上下标）
  → 断行（按宽度 + 语言规则切成行）
  → 排版（对齐、行高、缩进、省略号）
  → 段落对象（几何信息 + 绘制指令 + 命中测试）
```

## 2. 关键决定：整形与断行不自己造（ADR-0005）

文本整形（HarfBuzz 做的事）和断行算法（UAX #14）各有上千条规则，
自己写 = 用两年时间换一个更差的版本。**这不是偷懒，是止损。**

- **整形**：复用成熟实现（HarfBuzz 系 或 Skia 文本栈 或 平台 API：DirectWrite / CoreText）。
- **断行**：UAX #14 换行规则 + **CJK 标点禁则**（句号、逗号不置行首；开括号不置行尾）。
- **我们只写**：回退链、段落组装、命中测试、IME 组合渲染——这些才是 UI 库的本职。

## 3. 度量同源（铁律，原型期踩过的坑）

文本的**测量**和**绘制**必须用同一套字体度量。
布局引擎问"这段字多高"时得到的答案，必须等于渲染时实际画出来的高度。
两套度量 = 文字截断、基线漂移、行高抖动。全库只允许一处实现。

## 4. 字体回退链（中文不出现豆腐块的前提）

每个字符按"脚本 → 语言 → 平台"逐级回退：

| 平台 | 中文回退链 |
|---|---|
| Windows | 用户字体 → Microsoft YaHei UI → SimSun → 系统默认 |
| macOS | 用户字体 → PingFang SC → Hiragino Sans GB → 系统默认 |
| Linux | 用户字体 → Noto Sans CJK SC → 文泉驿 → fontconfig 默认 |

emoji 单独成链（Segoe UI Emoji / Apple Color Emoji / Noto Color Emoji）。
**字体许可**：分发打包时内嵌字体必须确认可再分发许可（思源黑体/Noto 是 OFL，可用；微软雅黑不可随包分发，只能用系统已装的）。

## 5. 段落排版

- 对齐：左/中/右/两端对齐（中文两端对齐需要标点悬挂，Phase 3）
- 行高：来自字体排印令牌，**不是字体度量的默认值**
- 最大行数 + 省略号（末尾省略，含"…展开"扩展点）
- 首行缩进、段间距
- 选区几何：`rects_for_range(start, end)` —— 返回一段文字的所有选区矩形（跨行时多个）
- 命中测试：`position_for_point(x, y)` —— 点击落在哪个字符间隙（文本编辑的地基）

## 6. 文本编辑与 IME 组合渲染

输入框的内部表示：`text + selection(anchor, focus) + composition(range)`。

- **组合态**：未上屏的拼音以下划线样式渲染，光标在组合区间内移动；
- **上屏**：`committed_text` 插入到光标处，组合区间清空；
- **候选框位置**：光标像素坐标上报给后端（见 `docs/02`），候选框跟在光标旁。

## 7. 验收标准

- [ ] 中文 1000 字混排（标点/英文/数字/emoji）无豆腐块、无错断行
- [ ] 同一文本在三个平台的行数与行高一致（同一字体下逐行一致）
- [ ] CJK 禁则测试集（行首禁则 20 例、行尾禁则 10 例）全过
- [ ] `rects_for_range` 跨行选区几何与视觉一致
- [ ] 省略号在任意宽度下不截断半个字符
- [ ] 测量与绘制同源：全文搜索只有一处度量实现

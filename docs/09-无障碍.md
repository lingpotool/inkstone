# 09 · 无障碍

> 一句话：**无障碍不是慈善功能，是"企业级"的验收线——读屏软件用不了，就不许叫 1.0。**

## 1. 语义树

与渲染树平行的一棵树，每个交互节点带语义信息：

| 属性 | 例子 |
|---|---|
| role | button / textbox / list / listitem / dialog / menu |
| name | "保存"、"搜索文档" |
| value | 滑块当前值、输入框文本 |
| state | disabled / checked / expanded / selected |
| description | 补充说明（tooltip 内容） |

- 语义树**自动**从组件树生成（组件声明 role/name，容器自动汇总）；
- 帧调度中同步更新，只提交变化节点（见 `docs/06` 帧阶段）；
- 语义树可快照、可断言——无障碍测试不靠耳朵，靠断言。

## 2. 平台桥接

| 平台 | 桥接 | 读屏软件验证 |
|---|---|---|
| Windows | UI Automation | NVDA（免费）+ 讲述人 |
| macOS | NSAccessibility | VoiceOver |
| Linux | AT-SPI | Orca |

桥接层是原生代码密集区，列为 Phase 3 最大工程量项，**不低估**。

## 3. 键盘与焦点

- 全键盘可达：Tab / Shift+Tab 顺序合理，方向键在复合组件内漫游（`primitives/roving_focus`）；
- 焦点环始终可见（focus-visible），永不裁切；
- 弹层打开 → 焦点圈禁；关闭 → 焦点归还给触发器；
- 快捷键经命令系统注册，读屏可朗读。

## 4. 视觉无障碍

- 对比度 ≥ WCAG 2.2 AA（CI 自动检查，见 `docs/13`）；
- 信息不只靠颜色传达（错误同时给图标与文字；涨跌同时给箭头与颜色）；
- 尊重系统偏好：减少动效、字号缩放（布局随字号放大不塌）。

## 5. 测试

- 语义树快照测试：组件 × 状态 → 断言 role/name/state；
- 键盘路径测试：不用鼠标完成示例库全部操作（自动化）；
- 真机读屏清单：三平台各一款，按场景走查（人工，发布前必做）。

## 6. 验收标准

- [ ] 读屏软件可正确朗读按钮、输入框、列表、对话框（三平台各一款）
- [ ] 焦点环在所有组件可见且不被裁切
- [ ] 弹层焦点圈禁与归还，自动化测试通过
- [ ] 字号放大到 200%，示例库无布局坍塌、无文字裁切
- [ ] 对比度 CI 检查零违规
